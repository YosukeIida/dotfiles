# 文機能の語彙

このファイルは、tsuzuri が一文ごとに付与する文機能の5つの欄（接続・役割・重要度・工夫・対応要件）について、既定の語・出典・語ごとの確認の仕方を列挙したものです。
欄の名前は閲覧アプリの画面に表示される名前と同じです。
一文にどの語を付与するか迷ったときは、その欄の表の「確かめ方／外すとき」を参照し、文が語に当たるかを確認してください。

## 判定の前提

文機能は AI が付与する目安で、正解ではありません。
人どうしでも判定はあまりそろわず、段落をまたぐ文の関係の一致は 62%[^prasad]、重要な命題の一致は中程度[^zeldes]と報告されています。

そのため、その欄の表に照らして合わなければ、その語を外すか選択し直してください。
ただし、必須の接続（`relation`）と重要度（`importance`）は外さず、合う語を選択し直してください。

分類もむやみに増やさないでください。
人どうしの分類の一致は分類の数にも左右され、Bayerl & Paul 2011 も分類の数を一致に影響する要因に挙げています。
文機能の単位は一文で、文の中の節どうしの関係は付与しません。

## 出典の読み方

各欄の語は出典の確かさで次の4つに分類されます。

- 文献の本文で定義を読んだ語：重要度の核と衛星（Carlson & Marcu 2001）。
- 別の論文の紹介で分類名を読んだ語：接続（市川 1978）と説明文の役割（木戸 1992）。原本の定義は読んでいません。
- tsuzuri が名付けた語：話法の6語と説明文の工夫。
- 非公開の手引きに基づく語：深度と小説の工夫（MaryCache の執筆手引き novel-craft。読み手は参照できません）。

表の「確かめ方／外すとき」は、どの種類の語でも tsuzuri で使用するための目安で、原本の定義を補うものではありません。

## 1. 接続（relation）

接続は市川孝 1978『国語教育のための文章論概説』の文の連接8類型から選択します。
表の定義は浅井美恵子「論説的文章における接続詞について」の紹介で読んだものです。

| 語 | 紹介された定義 | 確かめ方／外すとき |
|---|---|---|
| 順接 | 前文の内容を条件とする帰結を後文に述べます | 「だから」を入れて帰結として読むことができますか。単なる付け足しなら外してください。 |
| 逆接 | 前文の内容に反する内容を後文に述べます | 「しかし」で、前文からの予想に反しますか。並べて比較するだけなら対比を検討してください。 |
| 添加 | 前文に付け加わる内容を後文に述べます | 「そして」「さらに」で情報が増えますか。同じ内容の言い直しなら同列を検討してください。 |
| 対比 | 前文に対して対比的な内容を後文に述べます | 「一方」で、同じ観点から違いを比較できますか。予想を覆すことが中心なら逆接を検討してください。 |
| 転換 | 前文から転じ、別個の内容を後文に述べます | 「ところで」で話題を変えることができますか。同じ話題への付け足しなら外してください。 |
| 同列 | 前文と同等とみなされる内容を重ねて述べます | 「つまり」「言い換えると」で読むことができますか。別の情報を増やしているなら外してください。 |
| 補足 | 前文の内容を補足する内容を後文に述べます | 「なぜなら」「ただし」などで前文を支える説明になりますか。前文を離れて話を進めるなら外してください。 |
| 連鎖 | 前文に直接結びつく内容を後文に述べます。普通、接続語句は用いません | 接続語なしで自然につながりますか。ほかの型の接続語が適切なら、その型を検討してください。 |

表に挙げた接続語は判定の補助で、接続語の有無だけで型を判定しないでください。
文章の最初の文と、段落をまたいで離れた文に答える文には、8類型を無理に付与せず `段落の始まり` と記述してください。
`段落の始まり` は tsuzuri の値で、市川の第9の類型ではありません。

## 2. 役割（role）

役割は文章の種類に応じて語を選択し、配列で渡してください。
一文が複数の働きを持つときはすべて含め、最も強い働きを先頭に配置してください（「〜だから、〜すべきだ」なら主張・理由）。
先頭が主の役割として色とアイコンになり、2つ目からは副の役割として併記されます。
説明文の役割が3つ以上になったら、文を分割できないか確認してください。

### 説明文・意見文

説明文の役割は木戸光子 1992「文の機能に基づく新聞投書の文章構造」の6分類を使用します。
分類名と、意見か事実かの区分は、単艾婷・松村瑞子 2018「新聞社説におけるテクスト構造の一考察」（言語文化論究 40）の紹介で読んだものです。

| 語 | 区分 | 確かめ方／外すとき |
|---|---|---|
| 主張 | 意見 | 書き手が何を認めさせたいかを述べていますか。事実を知らせるだけなら外してください。 |
| 評価 | 意見 | 対象への価値判断を述べていますか。判断を含まない説明なら外してください。 |
| 理由 | 意見 | なぜその主張・判断をするかに答えていますか。前後の主張を支えていなければ外してください。 |
| 根拠 | 事実 | 主張を支える事実を示していますか。書き手の判断だけなら外してください。 |
| 解説 | 事実 | 対象の意味や仕組みを説明していますか。評価が中心なら外してください。 |
| 報告 | 事実 | 起きたことや確認したことを伝えていますか。提案や価値判断が中心なら外してください。 |

定義・例示・手順・前置き・まとめは既定に含めていないため、当たる語が無ければ近い語を無理に選択せず、tsuzuri の `review` 命令で記録してください。
論文の文を目的・背景・自分の研究・他の研究との比較などに分類する Argumentative Zoning（Teufel 1999）もありますが、役割の語を自動でその分類に切り替えないでください。

### 小説・物語

小説の役割は深度と話法の2つの軸から当たる語を選択し、同じ配列に含めてください。
描写か記号での回収かは役割ではなく工夫に含めます。
深度は地の文を外面・感覚・内面・生の声の4段の深さで書き分ける考え方です。

| 深度 | 確かめ方／外すとき |
|---|---|
| 外面 | 外から見える動作や様子を述べていますか。本人しか知ることができない感覚・思考なら外してください。 |
| 感覚 | 視点人物が感じる音・匂い・触覚などを述べていますか。外からの観察だけなら外してください。 |
| 内面 | 視点人物の考えや感情を述べていますか。身体の感覚だけなら外してください。 |
| 生の声 | 人物の声がそのまま出る近さですか。語り手が整理して説明しているなら外してください。 |

話法は Lancaster の Speech, Writing and Thought Presentation の手引きにある約25の分類から、tsuzuri が6つに絞ったものです。

| 話法 | 確かめ方／外すとき |
|---|---|
| 語り | 語り手が出来事を述べていますか。人物の発言・思考の提示が中心なら別の語を選んでください。 |
| 直接話法 | 人物の発言をその言葉として示していますか。引用符があるだけで判定せず、発言でなければ外してください。 |
| 間接話法 | 人物の発言内容を語り手が伝えていますか。人物の言葉を直接示すなら外してください。 |
| 自由間接話法 | 引用や報告の枠を省き、語りに人物の発言の声が混じっていますか。通常の語りや明示的な引用なら外してください。 |
| 直接思考 | 人物の考えをその言葉として直接示していますか。声に出した発言なら外してください。 |
| 自由間接思考 | 思考の報告の枠を省き、語りに人物の思考の声が混じっていますか。語り手の説明だけなら外してください。 |

## 3. 重要度（importance）

重要度は Carlson & Marcu 2001 の RST の注釈の手引きにある核と衛星の2つから選択します。
RST ではこの2つが関係の中の重さを表し、tsuzuri はそれを一文ごとの見直しに使用しています。

| 語 | 意味 | 確かめ方／外すとき |
|---|---|---|
| 核 | 関係の中で欠かせない文 | 消すと要件定義書の「言いたいこと」が失われますか。残るなら衛星を検討してください。 |
| 衛星 | 核を支える文 | 消しても「言いたいこと」は残るものの、説明や支えが減りますか。消すと「言いたいこと」が失われるなら外してください。 |

「最高・高・中」のような段階は設けないため、迷ったときは、ほかの文との関係と要件定義書に戻って判定してください。
迷ったときは、石黒 2014 が挙げた、要約で重要になる文の目安（一般的な内容の文・ほかの文をまとめる文・前提の状況を設定する文・評価や主張の文）も手がかりにしてください。
この目安も同じ論文の紹介で読んだもので、判定の手がかりにとどめ、文機能の語には追加しません。

## 4. 工夫（technique）

工夫は実際に使ったものだけを配列に含め、無ければ `[]` にしてください。
名前から効果を決めつけず、文がその働きを果たしているかを確認してください。
小説の工夫と説明文の工夫は別の語で、説明文の役割の文に小説の工夫を付与するなど種類を混ぜると、`write` 命令が警告します。

### 小説

小説の工夫は MaryCache の執筆手引き novel-craft（非公開）の各節によるもので、表の「出典の箇条」はその節の名前です。

| 語 | 出典の箇条 | 確かめ方／外すとき |
|---|---|---|
| シャレード | 「シャレード」 | 動作や物から言外の意味を読み取ることができますか。意味を直接説明するだけなら外してください。 |
| 描写 | 「描写」の第1項 | 具体的な様子を描いていますか。既出の対象を短い呼び名で呼び戻すだけなら外してください。 |
| 記号での回収 | 「描写」の第2項 | すでに描写したものを短い記号で呼び戻しますか。初出で前の描写がなければ外してください。 |
| フォーカスの予告 | 「深度」の「視点人物を移すときは」 | 次の視点人物への移行を先に示していますか。視点移動がなければ外してください。 |
| 五感 | 「地の文の技法」 | 視点人物の感覚が具体的に働いていますか。感覚語を置いただけなら外してください。 |
| 欠落を書く | 「地の文の技法」 | 無いもの・欠けたものによって状態を伝えていますか。意味のある欠落でなければ外してください。 |
| 文長を揺らす | 「地の文の技法」 | 前後の文との長短がリズムを作っていますか。一文だけを見て付けないでください。 |

### 説明文

説明文の工夫は k16shikano 氏の文章規範 japanese-tech-writing の「段落と論証の構成」の箇条に、tsuzuri が命名したものです。

| 語 | 元の箇条 | 確かめ方／外すとき |
|---|---|---|
| 関係の明示 | 第3項：段落の先頭で接続表現を示します | 前の内容との関係を接続表現で示していますか。関係が読み取ることができないなら外してください。 |
| 否定の根拠 | 第7項：「AではなくB」に根拠を一文添えます | Aを退ける根拠が伴っていますか。否定とBだけなら外してください。 |
| 対比定義 | 第8項：述部を同じ型にします | 対比する定義の述部が揃い、同じ観点で比較できますか。型が揃わなければ外してください。 |
| 譲歩 | 第9項：事実の確認にとどめます | 相手の事実を認める働きですか。相手の主張全体に同意していれば外してください。 |
| 命題の書き出し | 第11項：否定する命題を「」で書き出します | 何を否定するかを命題として示していますか。対象が曖昧なら外してください。 |
| 誤解の先回り | 第6項：誤った解釈を否定してから理由を述べます | 起こり得る誤解と、それを退ける理由がありますか。否定だけなら外してください。 |

これらの語は、文が用いた工夫を確認するためのもので、語の検査や表現の一律な禁止には使用しないでください。

## 5. 対応要件（place）

対応要件には既定の語が無く、照らした要件定義書の項目を、見出しと同じ番号と項目名で `"8. 言いたいこと"` のように記述します。
項目は「1. 依頼」「2. 書く理由」「3. 公開する場所と読み手」「4. 範囲と範囲外」「5. 制約」「6. 読んだあと」「7. 書き手の立場」「8. 言いたいこと」「9. 文章の形」の9つです。

設計書の段落は `place` に含めず、`write --para p2` のように段落の番号で指してください。
照らした要件定義書のバージョンは、`write --requirements` で結び付けます。

指した項目を実際に参照し、その文がその項目を担っていると説明できなければ、選択し直してください。
`place` は空にできません。

## 語の追加と、未決の事項

利用者が語を追加するときは、記録フォルダの `vocab.json` の `relation` と `role` に語の配列で追加します（`{"relation":["応答"],"role":["案内"]}`）。
追加した語の意味・出典・確認の仕方も、利用者と共有してください。

`technique` の未知の語は警告つきで保存され、`vocab.json` に追加してもその警告は消えません。
`importance` は核と衛星の2つから増やすことができません。

説明文の役割に定義・例示・手順・前置き・まとめを追加するか、話法の絞り方を変更するか、市川と木戸の原本で定義を再確認するかは、まだ決定していません。
それまでは、紹介で読んだ語と tsuzuri が名付けた語を、原本で確認した分類として扱わないでください。

[^prasad]: Prasad, R. et al. 2017, Proceedings of the 18th SIGdial.

[^zeldes]: Zeldes, A., Conhaim, K. & Levine, L. 2026, arXiv:2603.27358.

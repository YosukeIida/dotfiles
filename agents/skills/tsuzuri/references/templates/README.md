# README
道具やスキルを紹介し、導入方法と使用方法を伝える文章（GitHub の README など）に使用します。

## 文章の形の既定

要件定義書の「9. 文章の形」には次を既定として記述し、依頼に合わせて修正してください。

- 種類: README（道具の紹介と使用方法）
- 長さ: 画面3〜5枚ほど
- 媒体: GitHub の Markdown（`export --flavor gfm`）
- 文体: 文語の敬体（です・ます）

## 骨組み

見出しは見出しのブロックとして記録し、`<…>` は依頼と材料で埋めてください。
材料に無い節は作らずに外してください。

````markdown
# <名前>

<何をする道具かを一文で>
<誰の、何が楽になるかを一文で>

## 何ができるか

## 導入方法

```bash
<導入のコマンド>
```

## 使用方法

## 仕組み

## ライセンス
````

## 段落の並びの考え方

- 最初の段落で「何をする道具か」を渡し、読み手が導入方法を読む前に、自分に必要かどうかを判断できるようにします。
- 「導入方法」は、そのまま貼って動作するコマンドの箱にします。前提（使用する言語の版や、先に導入しておく道具）は箱の前に書きます。
- 「使用方法」は、導入した直後に最初に実行する操作から並べます。
- 「仕組み」は、使用するのに不要な読み手が読み飛ばせるように、使用方法の後ろに配置します。

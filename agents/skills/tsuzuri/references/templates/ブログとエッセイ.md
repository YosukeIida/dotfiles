# ブログとエッセイ
経験や考えを、自分の声で語る文章（個人のブログ・エッセイ・note など）に使用します。

## 文章の形の既定

要件定義書の「9. 文章の形」には次を既定として記述し、依頼に合わせて修正してください。

- 種類: ブログ・エッセイ
- 長さ: 2,000〜4,000字ほど
- 媒体: ブログや note の Markdown
- 文体: 書き手の普段の話し方に合わせて、口語の常体（だ・である）か口語の敬体（です・ます）のどちらかに決めます。文中で混ぜません

## 骨組み

見出しは見出しのブロックとして記録し、`<…>` は依頼と材料で埋めてください。
材料に無い節は作らずに外してください。

````markdown
# <題：何があったか、何を考えたか>

<書き出し：読み手が自分ごとにできる場面か問い>

## <出来事>

## <そこで考えたこと>

## <今どうしているか、次にどうするか>
````

## 段落の並びの考え方

- 書き出しは、要約ではなく、読み手が自分の経験に引き寄せられる場面か問いにします。
- 出来事は、書き手の経験として材料に記述されたことだけを使用し、経験を創作しません。
- 考えたことは、出来事のどの部分から生じたかが理解できるように、出来事の直後に配置します。
- 最後は教訓でまとめず、書き手が今どうしているか、次にどうするかで閉じます。
